## 🚀 Featured Projects

### 🧭 Multi-Agent Travel Planner
**LangGraph · MCP · FastAPI · PostgreSQL · AviationStack · Tavily · OpenWeatherMap**

A supervisor-driven system of **six specialised agents** (flights, hotels, weather, budget, itinerary) that plans trips with live data.
- **Supervisor + input guardrail** validates prompts, extracts structured travel constraints and calls only the agents needed
- **Three real-time MCP data sources**: AviationStack, Tavily and a custom FastMCP OpenWeatherMap server
- **Human-in-the-loop approvals** using LangGraph `interrupt()` with PostgreSQL-backed checkpointing, so workflows can pause and resume
- FastAPI REST endpoints, a Jinja2 dashboard and a CLI runner with a MemorySaver fallback for testing

🔗 [View repository](https://github.com/Jigil-ak/REPLACE_WITH_TRAVEL_PLANNER_REPO_NAME)

### 🩺 Medical Chatbot using RAG & LLMs
**Python · LangChain · Pinecone · Hugging Face (FLAN-T5) · Flask · Streamlit**

A context-aware medical Q&A chatbot built on Retrieval-Augmented Generation.
- Document ingestion, cleaning, parsing, chunking and embedding pipeline
- Semantic search and vector retrieval through **Pinecone**
- Answers generated by a Hugging Face **FLAN-T5** model, served via Flask and Streamlit

🔗 [View repository](https://github.com/Jigil-ak/Medical-Chatbot-with-LLMs-LangChain-Pinecone-Flask-AWS)

### 🦷 Dental X-ray Analysis using Deep Learning & YOLO
**Python · TensorFlow · YOLOv5 · OpenCV · Flask · Streamlit**

Deep learning pipeline for analysing dental X-ray images.
- **CNN models** for dental caries detection
- **YOLO object detection** to identify tooth categories and implants
- Image preprocessing and augmentation to improve generalisation
- Trained models integrated into a web app for real-time inference

🔗 [View repository](https://github.com/Jigil-ak/Enhanced-Dental-Image-Analysis)
